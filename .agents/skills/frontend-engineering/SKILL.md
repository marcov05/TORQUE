# Frontend Engineering

Use esta orientação ao implementar o frontend TORQUE, a partir da Fase 3 autorizada.

- Usar React com TypeScript estrito, Vite, Tailwind CSS, React Router, Axios, Context API, Lucide React, React Hook Form e Zod.
- Manter páginas, componentes reutilizáveis, hooks, serviços HTTP, tipos e utilitários em módulos separados. Não colocar regras de domínio em componentes visuais.
- Usar formulários tipados e validação consistente; tratar estados de carregamento, erro, vazio, confirmação e sucesso.
- Implementar a identidade visual definida na especificação (tema claro, sidebar grafite, vermelho de destaque) com componentes reutilizáveis.
- Garantir navegação, listagens, formulários e ações administrativas em desktop, tablet e celular; não depender de hover ou esconder ações essenciais no mobile.
- Respeitar as permissões e estados retornados pela API. A validação da interface nunca substitui a validação do backend.
- Em ordens de serviço, seguir a seção 27 da especificação: criação sempre ABERTA, ações segundo a matriz, aprovação explícita e históricos visíveis.
- Não usar `any`, JavaScript puro para contornar TypeScript, dados mock como implementação final ou botões sem ação real.
- Não iniciar o frontend antes da validação da Fase 2.
