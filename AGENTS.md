# TORQUE — instruções do projeto

## Objetivo
Sistema web para administração de oficinas de motocicletas, conforme `README.md` e a especificação mestre fornecida pelo usuário.

## Regras de trabalho
- Respeite as cinco fases documentadas no README. Conclua uma fase e aguarde autorização explícita antes de iniciar a seguinte.
- Preserve os requisitos de stack: React, TypeScript, Vite, Tailwind, React Router, Axios, Context API, Lucide, React Hook Form e Zod; Node.js, TypeScript, Express, JWT, bcrypt, mysql2/promise, Helmet e express-rate-limit; MySQL 8, Docker Compose e Nginx.
- Não adicionar dados fictícios como substitutos permanentes, funcionalidades sem implementação, credenciais no código, nem `any` para contornar tipagem.
- Manter responsabilidades separadas: domínio/serviços, repositórios, controllers e apresentação.
- Validar entradas no backend, proteger operações com autenticação/autorização e usar transações para operações relacionadas.
- Preservar arquivos e dados existentes. Não executar operações destrutivas sem autorização explícita.
- Não declarar requisitos concluídos sem evidência de validação. Relatar arquivos, decisões, validações, resultados e pendências ao concluir cada fase.

## Skills locais
Consulte as instruções específicas em `.agents/skills/` antes de alterar backend, frontend ou banco/infraestrutura.
